# Strata

Cliente de escritorio moderno para bases de datos, con una experiencia **keyboard-first**: consola SQL, paleta de comandos y flujos completables sin ratón.

## Stack previsto

Electron + `electron-vite` + Vue 3 (Composition API) + TypeScript, con Pinia, CodeMirror 6 para el editor SQL y una identidad visual derivada de los design tokens de [BRAID](../Braid).

Compatibilidad inicial: PostgreSQL y SQLite.
